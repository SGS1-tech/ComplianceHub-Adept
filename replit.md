# ComplianceHub — AdeptLink

## Overview
A compliance tool for Vietnamese food exporters targeting the Canadian market. Provides HS Code lookup, CFIA checklists, allergen checking, bilingual (EN/FR) label guidance, and certificate information.

The project is a single self-contained HTML file (`index.html`) served via Python's built-in HTTP server on port 5000.

## Structure
- `index.html` — Main application file (copied from `compliance_adept-link 1.html`)
- `compliance_adept-link 1.html` — Original source file from GitHub import

## Running
The app is served with: `python3 -m http.server 5000 --bind 0.0.0.0`

## User Preferences
- Language: Vietnamese (vi)
